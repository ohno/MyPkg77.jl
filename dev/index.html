MyPkg77.jl

Testing for PkgFactory MCP

This package requires Julia 1.12 or later because it uses Pkg workspaces. See [compat] in Project.toml for the supported versions.

Quick Start

Run the following command in the Julia REPL or a notebook:

import Pkg; Pkg.add(url="https://github.com/ohno/MyPkg77.jl.git")

After installation, run the following to load the package and verify it works:

julia> import MyPkg77; MyPkg77.hello()"Hello, World!"
